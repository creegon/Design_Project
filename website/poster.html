Motivation & Problem

Multiple LLMs now embed cryptographic watermarks for provenance. When an observer receives text, which model produced it?

Two Attribution Paradigms

Watermark (Active)

  • Per-model KGW key
  • z-test against each key
  • Strong on clean text

Fingerprint (Passive)

  • TF-IDF n-gram features
  • 4-way classifier
  • No key needed

Research Gaps

  1. Does watermarking compress inter-model distributional differences?
  2. Head-to-head watermark vs. fingerprint attribution under attack?
  3. Can sentence-level watermarks (SimMark) complement KGW?

Method — KGW Watermarking

Kirchenbauer et al., ICML 2023. Token-level green/red list partition with logit bias.

Z = (|s|G − γT) / √(γ(1−γ)T)

Parameters: γ = 0.25, δ = 2.0, z-threshold = 3.0, selfhash context = 4

Models: LLaMA-3.2-1B, LLaMA-3.2-3B, Gemma-2B, Phi-2

Attacks: Synonym substitution 10–70%, Insert/Delete 10–30%, Sentence reorder, Neural paraphrase (Qwen-3)

F3 Hybrid KGW + SimMark Watermarking

SimMark (EMNLP 2025) embeds watermarks in inter-sentence cosine similarity patterns. We combine it with KGW: each token uses KGW bias, each sentence checked against SimMark constraint via rejection sampling.

Conclusions

  1. Watermarking compresses distributions — makes different models look more alike (Finding 1).
  2. Watermark & fingerprint have non-overlapping failure modes — crossover at 50–70% perturbation (Finding 2).
  3. KGW + SimMark are complementary — Hybrid OR achieves 100% on poetry where neither alone does (Finding 3).
  4. Neural paraphrase defeats KGW alone — only 1/17 survived (Finding 4).
  5. Aggressive attack remains open — both KGW and SimMark fail under heavy compression.

Future Work

  • Hybrid attribution classifier: combine KGW z-scores + TF-IDF features in one model
  • Neural paraphrase attacks: extend attack suite with GPT/Claude rewrite
  • Efficient hybrid generation: sentence-level beam search (SentBS) or IterGen backtracking to replace rejection sampling
  • Adaptive intervals: auto-tune SimMark interval per text type

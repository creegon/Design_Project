Motivation & Problem

Multiple LLMs now embed cryptographic watermarks for provenance. When an observer receives a piece of text, which model produced it? This is the source-attribution problem. Two paradigms exist in isolation:

Watermark (Active)

  • Per-model KGW key
  • z-test against each key
  • Strong on clean text
  • Brittle under attack

Fingerprint (Passive)

  • TF-IDF n-gram features
  • 4-way classifier
  • No key needed
  • Graceful degradation

Research Gaps:

  1. Does watermarking compress inter-model distributional differences?
  2. Head-to-head watermark vs. fingerprint attribution under attack?
  3. Can sentence-level watermarks (SimMark) complement token-level (KGW)?
Method — KGW Watermarking

Kirchenbauer et al., ICML 2023. Token-level green/red list partition with logit bias. Detection via z-test on green token count.

Z = (|s|G − γT) / √(γ(1−γ)T)

Parameters: γ = 0.25 · δ = 2.0 · z-threshold = 3.0

Models: LLaMA-3.2-1B, LLaMA-3.2-3B, Gemma-2B, Phi-2

Attacks: Synonym sub. 10–70%, Ins/Del 10–30%, Sentence reorder, Neural paraphrase (Qwen-3)

F3 Hybrid KGW + SimMark Watermarking

SimMark (Aghdam et al., EMNLP 2025): sentence-level watermark via inter-sentence cosine similarity. Combined with KGW: each token gets green-list bias, each sentence checked for SimMark constraint via rejection sampling. Detection: OR logic — either detector positive → watermarked.

Hybrid Generation Pipeline:
  Token → KGW LogitsProcessor (green-list bias δ=2.0)
  Sentence complete → Check SimMark constraint (cos_sim ∈ [0.75, 0.83])
    ✓ Accept  |  ✗ Reject & regenerate with KGW (max 50 retries)
Hybrid Detection: KGW z > 3.0 OR SimMark z > 2.0 → watermarked

A real neural paraphraser is dramatically more destructive than symbolic synonym substitution — z-score inverts sign in 10/17 cases. Only an extreme initial z-score of 8.0 survived. Average semantic similarity post-paraphrase: 0.29.

Conclusions
  1. Watermarking compresses distributions — inter-model weighted diff drops from 0.76 to 0.24 (Finding 1).
  2. Watermark & fingerprint: non-overlapping failure modes — watermark collapses cliff-like at 70% synonym; fingerprint degrades gracefully from 77% to 63% (Finding 2).
  3. KGW + SimMark are complementary — Hybrid OR reaches 100% on poetry; neither alone exceeds 67% (Finding 3).
  4. Neural paraphrase defeats KGW alone — only 1/17 survived, average z-decay of 5.07 (Finding 4).
  5. Aggressive attack remains open — sentence compression/merging defeats both KGW and SimMark.

Practical recommendation: Generation may use either watermark; detection should always use hybrid OR-logic to maximize coverage across text types and attack intensities.

Future Work
  • Hybrid attribution classifier: feed both KGW z-scores and TF-IDF features into a single model, exploiting non-overlapping failure modes
  • Neural paraphrase attacks: extend attack suite with GPT-4 / Claude rewrite, back-translation
  • Efficient hybrid generation: sentence-level beam search (SentBS) or IterGen backtracking to replace rejection sampling
  • Adaptive intervals: auto-tune SimMark similarity interval per text type (poetry vs. prose)
  • More model families: Mistral-7B, Qwen-2.5, closed-source proxy
